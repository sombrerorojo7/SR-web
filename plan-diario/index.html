Cómo usarlo

  • Exporta tu hoja como CSV desde Google Sheets o Excel.
  • Puedes pegar un link público del CSV o importar uno o varios archivos manualmente.
  • La app guarda los datos en este navegador del teléfono.
  • Los prospectos no se suben a GitHub ni a ningún servidor desde esta app.

Columnas reconocidas

  • Nombre de la Empresa, Ciudad, Campaña y Plan Sugerido.
  • Estado de contacto, Estado Pipeline y Fecha de último contacto.
  • Próximo Contacto, Link WhatsApp, Link Propuesta y Confirmación si existe.
  • También funciona si algunas columnas están vacías.
  • Si el enlace privado no carga, usa “Importar CSV” como respaldo.
